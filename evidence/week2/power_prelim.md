# 검정력·비용 예비 추정 — 승인 전 참고용 (Week2-D6, 2026-09-14)

**계산만. 실행·승인 없음.** 풀은 미확정(교수님 문서 5절 질문 2 대기). 아래는 "BCB 적격 풀이 승인된다면" 의 가정 아래 프로브 4 결과와
합성 검증으로 파일럿 규모를 가늠한 것이다.

## 1. 분석기 검증 (`scripts/gap_analysis.py --synthetic`, 10,000 부트스트랩, seed 20개, 300 과제 × 6 arm × k=3) → `gap_synthetic.json`

| 항목 | 결과 | 기준 |
|---|---|---|
| (a) 상호작용 없음 → "통과" 비율 | **0 / 20 = 0%** | ≤ 8% |
| (b) 10pp 상호작용 → CI 가 추정 대상 포함 | **20 / 20 = 100%** | ≥ 90% |
| (c) 결정적 반복 경고 | 발생 | — |
| (d) 미측정 $ → None | 확인 | — |

(b) 의 "추정 대상" 은 **oracle gap 이 아니라 교차 적합 통계량의 기대값**(같은 확률에서 데이터를 거듭 뽑았을 때의 평균, 몬테카를로)이다.
oracle gap 을 목표로 잡으면 CI 는 거의 항상 빗나간다 — 아래 §2 가 그 이유다.

## 2. 예상과 달랐던 것: k=3 교차 적합은 참 상호작용을 크게 깎아 잰다

합성 모형(arm 기저 성공률 0.5 ± 0.05, 과제 효과 sd 0.15, 과제별 최선 arm 하나에 +interaction), 300 과제, seed 5개 평균:

| 참 상호작용 | oracle gap (참 확률) | 교차 적합 추정 대상 k=3 | k=5 | k=9 |
|---|---|---|---|---|
| 0.1 | 0.028 | −0.042 | −0.044 | −0.039 |
| 0.2 | 0.096 | −0.028 | −0.022 | −0.007 |
| 0.3 | 0.173 | −0.007 | 0.015 | 0.052 |
| 0.5 | 0.291 | 0.055 | 0.117 | 0.200 |

이유: 과제별 최선 arm 을 집합 1(k=3 이면 반복 2개의 Bernoulli 평균)에서 6개 중 고르는 선택은 잡음이 커서 자주 틀리고, 최선 고정 arm 은 300 과제를
합쳐 고르므로 정확하다. 그래서 "사후 선택 − 최선 고정" 은 참 상호작용이 0.3 이어도 0 근처다. **10pp 문턱을 k=3 교차 적합 gap 에 걸면
참 상호작용 ≈ 0.5 이상이어야 통과한다.** 설계 §4-3 의 "3회 반복 교차 적합은 엄밀한 상한이 아니다" 는 이 정도로 강한 경고였다.
함의(판단 대상, 제안 아님): (i) 문턱을 교차 적합 gap 이 아니라 다른 추정량(예: 선택 잡음을 보정한 추정)에 걸거나, (ii) k 를 키우거나(비용 ∝ k),
(iii) 과제별 선택을 6 arm 전체가 아니라 사전 등록한 2~3 arm 으로 줄여 선택 잡음을 낮추는 것. 어느 것도 아직 설계에 반영하지 않았다.

## 3. N 추정 (Δ = 10pp, α = 0.05, power 0.8, N = ((z_0.975 + z_0.8)·σ/Δ)²)

| σ 의 출처 | σ (과제별 차이 sd) | N |
|---|---|---|
| 프로브 4 A/B single 2-arm 대리: 과제별 max(A,B) − B (k=1, 표본 내) | 0.181 (평균 0.033) | 26 |
| 합성 6-arm k=3 교차 적합 차이 (상호작용 0.3) | 0.391 | 120 |

2-arm 대리는 교차 적합이 아니고 k=1 이라 과소추정이다. 6-arm 합성값 120 은 확인 집합 349 안에 들지만, §2 때문에 "N 이 충분해도 문턱을 못 넘는"
상황이 기본값이다. 실제 σ 는 파일럿(k=3, 탐색 60)에서 `gap_analysis.py --power` 로 다시 잰다.

## 4. 비용·시간 (승인 시 파일럿: 탐색 60 × 6 arm × k=3)

프로브 4 단가: A $0.003 / B $0.006 per 호출 (BCB 프롬프트 ≈ 380 토큰, 완성 ≈ 350~540 토큰).
- 과제·반복당 ≈ s0 $0.003 + A-self $0.004 + A-self×k ≈ b_cont(≈$0.012, B-expert 1회 중앙값 가정) + A-role $0.004 + B-expert $0.012 + B-solo $0.006 ≈ **$0.04**
- 탐색 60 × k=3 ≈ **$7.5**; 확인 349 × k=3 ≈ **$44**. b_cont 는 파일럿 0회차에서 실측 후 갱신.
- 채점 시간: 과제·반복당 컨테이너 ≈ 1(s0 가시) + 6(히든) + ~8(계속 arm 가시) ≈ 15회 × ~5s ≈ 75s → 탐색 60 × 3 ≈ **3.8h**, 확인 349 × 3 ≈ **22h** (직렬).
- D1 원장 cap 은 사전 등록값으로: 파일럿 $10 제안값은 위 추정과 부합.
