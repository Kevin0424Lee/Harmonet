# Evidence

This directory contains curated benchmark and validation artifacts that are
safe to publish.

Raw provider responses, local logs, `.env` files, PID files, caches, and full
runtime output directories are intentionally excluded. The retained files are
summary-level artifacts for reproducibility and review:

- `g1/`: final G1 benchmark summaries and V1/V2 comparison notes.
- `g2/`: scaling, container, and Track C validation artifacts.
- `g3_24h/`: 24-hour reliability, load, recovery, security, and cost summaries.
